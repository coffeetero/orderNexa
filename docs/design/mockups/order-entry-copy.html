KindChange
layoutCopy button next to the Search magnifier. Enabled as soon as a customer is entered (no department needed); with no order started, Copy starts a new order using the copied order's department/event. Search stays as it is (all customers, the current date).
workflowCopy order drawer (right side, 460px wide so the three filters fit on one row). Orders from: Last <weekday> (default: same weekday as the production date, one week back), Yesterday (the day before the production date) or Date. Choosing one fills the date; typing a date switches it to Date. Code filters by production time.
workflowLists this customer's orders for that date, every department, grouped by Department/Event: each group shows its order (order no., code, invoice no.) and its lines. Checkboxes are on the right; the group checkbox checks or clears all of its lines.
workflowEach line has a checkbox, all checked, with a check all box; uncheck to copy all except. Inactive items are unchecked and cannot be checked. An item with no price today is flagged; leaving it checked copies it anyway. Copy adds the checked lines to the current order (in addition), priced from today's price book; an item already on the order gets the copied quantity added to its line. Nothing is saved until the order is saved.
cosmeticCopied lines show a small copied label (plain text) and a light tint. Changing the quantity clears it. On screen only for now.
dataUses the existing order list and order detail APIs and the items already priced for the current order. No new database function, table or column. (Built 2026-11-26.)
